## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser→API (`/auth/refresh`, replayed requests) | Expired access cookie crosses; refresh cookie decides bounce vs silent retry |
| bounce URL → Login (`?redirect=`) | Attacker-craftable query crosses into post-login navigation |
| sessionStorage draft slot | Same-origin per-tab storage; corrupt or foreign shape crosses into form state |

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |

| T-05-01 | Denial of service | api.js shared refresh promise | high | mitigate | One module-level in-flight POST /auth/refresh; concurrent 401s await the same promise (proven in 05-02 protocol) |
