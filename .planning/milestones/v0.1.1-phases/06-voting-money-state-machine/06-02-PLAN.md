<objective>
Implement VOT-02 annual-limit accounting: add CONCLUIDO to the annualTotalCents statuses array so that spent requests continue counting toward the requester's annual cap. This prevents the bypass where a requester submits up to the limit, gets approved/spent (CONCLUIDO), then submits new requests that auto-approve because CONCLUIDO was excluded from the sum.

Purpose: Close the annual cap bypass loophole by making CONCLUIDO requests count toward annualTotalCents, with a unit test proving the fix.
Output: Updated annualTotalCents in requestService.js + characterization test in voting.test.js.
</objective>
