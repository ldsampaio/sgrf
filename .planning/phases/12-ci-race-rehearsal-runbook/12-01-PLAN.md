# Plan 12-01: Bounded CI Wait Window with Target-SHA Validation

## Context

Phase 11 proved the apply path is guarded and idempotent. The next safety layer is the CI wait window: the tool must wait only within a bounded window for the canonical target-SHA main and tag CI runs, and any pending, contradictory, wrong-SHA, failed, or newly divergent evidence must abort without a remote write.

## Plan

1. Implement `awaitCIRuns` in `tools/release-close/ci-check.js` with bounded wait window
2. Validate target-SHA for main and tag CI runs
3. Abort on pending, contradictory, wrong-SHA, failed, or newly divergent evidence
4. Return structured evidence with action results, timestamps, full SHAs, run/job/check IDs

## Requirements

- SAFE-05: CI evidence is bounded, validated, and abort-on-uncertain
- OPS-03: structured evidence with action results, timestamps, full SHAs, run/job/check IDs
- OPS-04: partial-state next action

## Implementation

### `ci-check.js` — new module

```javascript
export async function awaitCIRuns(options) {
  const { ghClient, repo, targetSha, timeoutMs = 60000, pollIntervalMs = 5000 } = options;
  
  const start = Date.now();
  const evidence = {
    action: 'ci-wait',
    timestamp: new Date().toISOString(),
    targetSha,
    runs: [],
    aborted: false,
    abortReason: null,
    nextAction: null,
  };

  while (Date.now() - start < timeoutMs) {
    const [mainRun, tagRun] = await Promise.all([
      ghClient.getMainCIRun(repo, targetSha),
      ghClient.getTagCIRun(repo, targetSha),
    ]);

    // Validate target-SHA match
    if (mainRun && mainRun.headSha !== targetSha) {
      evidence.aborted = true;
      evidence.abortReason = `main run headSha ${mainRun.headSha} !== target ${targetSha}`;
      evidence.nextAction = 're-verify main SHA and retry';
      return evidence;
    }
    if (tagRun && tagRun.headSha !== targetSha) {
      evidence.aborted = true;
      evidence.abortReason = `tag run headSha ${tagRun.headSha} !== target ${targetSha}`;
      evidence.nextAction = 're-verify tag SHA and retry';
      return evidence;
    }

    // Check for contradictory evidence (main complete with failure while tag still pending)
    if (mainRun && mainRun.status === 'completed' && mainRun.conclusion === 'failure') {
      evidence.aborted = true;
      evidence.abortReason = `main CI run ${mainRun.id} failed`;
      evidence.nextAction = 'fix main CI and rerun';
      return evidence;
    }

    // Both complete and successful
    if (mainRun && mainRun.status === 'completed' && mainRun.conclusion === 'success' &&
        tagRun && tagRun.status === 'completed' && tagRun.conclusion === 'success') {
      evidence.runs = [mainRun, tagRun];
      evidence.nextAction = 'proceed to mutation';
      return evidence;
    }

    // Pending — wait and retry
    await sleep(pollIntervalMs);
  }

  // Timeout — abort
  evidence.aborted = true;
  evidence.abortReason = `CI wait exceeded ${timeoutMs}ms timeout`;
  evidence.nextAction = 'rerun CI and retry';
  return evidence;
}

function sleep(ms) {
  return new Promise(resolve => setTimeout(resolve, ms));
}
```

### Integration with `release-close.js`

- Call `awaitCIRuns` before any mutation in `runApply`
- Pass `ghClient`, `repo`, `targetSha` from the preflight data
- Abort if `evidence.aborted === true`
