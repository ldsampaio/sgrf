# Plan 13-01: Fresh Zero-Mutation Preflight Verification

## Context

Phase 13 is the live release phase. Before any mutation, we must run a fresh zero-mutation verification to confirm the current state of the repository: tag, main, CI, Release, and Milestone.

## Plan

1. Implement `freshPreflight` in `tools/release-close/verify.js`
2. Run fresh reads for all preflight checks
3. Return structured evidence with zero mutations
4. Integrate with the CLI `--verify` command

## Requirements

- REL-02: Fresh zero-mutation verification before any mutation
- REL-03: Reviewed factual notes, displayed plan, explicit operator confirmation
- REL-04: Recovery declared complete only after fresh remote reads confirm all state

## Implementation

### `verify.js` — add `freshPreflight`

```javascript
import { ghClient } from './gh-client.js';
import { renderEvidenceJson } from './evidence.js';

export async function freshPreflight(options) {
  const { repo, targetSha, version } = options;
  const evidence = {
    action: 'preflight',
    timestamp: new Date().toISOString(),
    targetSha,
    version,
    mutations: 0,
    checks: {},
    aborted: false,
    abortReason: null,
    nextAction: null,
  };

  // 1. Verify tag exists and peels to correct commit
  const tagRef = await ghClient.getTagRef(repo, version);
  if (!tagRef || !tagRef.data) {
    evidence.aborted = true;
    evidence.abortReason = `tag ${version} missing`;
    evidence.nextAction = 'create tag and retry';
    return evidence;
  }
  const tagObject = await ghClient.getTagObject(tagRef.data.ref);
  if (!tagObject || tagObject.data.sha !== targetSha) {
    evidence.aborted = true;
    evidence.abortReason = `tag ${version} does not peel to ${targetSha}`;
    evidence.nextAction = 'verify tag and retry';
    return evidence;
  }
  evidence.checks.tag = { ok: true, sha: tagObject.data.sha };

  // 2. Verify main ref matches target SHA
  const mainRef = await ghClient.getMainRef(repo);
  if (!mainRef || mainRef.data.sha !== targetSha) {
    evidence.aborted = true;
    evidence.abortReason = 'main ref does not match target SHA';
    evidence.nextAction = 'verify main and retry';
    return evidence;
  }
  evidence.checks.main = { ok: true, sha: mainRef.data.sha };

  // 3. Verify CI runs for target SHA
  const ciRuns = await ghClient.listCiRuns(targetSha, 'main');
  const requiredRuns = [36095855139, 36095872529];
  const completedRuns = ciRuns.data.runs.filter(
    r => r.status === 'completed' && r.conclusion === 'success'
  );
  const missingRuns = requiredRuns.filter(id =>
    !completedRuns.some(r => r.id === id)
  );
  if (missingRuns.length > 0) {
    evidence.aborted = true;
    evidence.abortReason = `CI runs missing or not successful: ${missingRuns.join(', ')}`;
    evidence.nextAction = 'rerun CI and retry';
    return evidence;
  }
  evidence.checks.ci = { ok: true, runIds: completedRuns.map(r => r.id) };

  // 4. Check for existing Release
  const release = await ghClient.getReleaseByTag(version);
  evidence.checks.release = release || null;

  // 5. Check for existing Milestone
  const milestones = await ghClient.listMilestones();
  const milestone = milestones.data.find(m => m.title === version);
  evidence.checks.milestone = milestone || null;

  evidence.nextAction = 'ready for operator review';
  return evidence;
}
```

### CLI integration

```javascript
// In release-close.js verify command:
const evidence = await freshPreflight({ repo, targetSha, version });
if (evidence.aborted) {
  io.stderr.write(`ABORTED: ${evidence.abortReason}\n`);
  return 1;
}
io.stdout.write(renderEvidenceJson(evidence) + '\n');
```
