## Phase Scope Note (read first)

**This phase builds NO new UI surfaces.** Phase 1 (CI Regression Gate) ships CI infrastructure only:
`.github/workflows/ci.yml` (plan 01-01), a deliberate red-proof (plan 01-02), branch protection +
an `AGENTS.md` note (plan 01-03). RESEARCH.md states the footprint verbatim: *"No src/ changes.
The rest of the repo is untouched — this phase's footprint is intentionally one workflow file + one
docs edit."* [CITED: 01-RESEARCH.md, Recommended Project Structure].

The word "frontend" in the phase goal means *run `npm run build` as a CI job* — not UI work. The
existing Vue 3 + Vite SPA (`frontend/`) is **unchanged and unviewed** by this phase; the only
frontend involvement is the build command compiling it green in CI.

**Consequences for downstream consumers:**
- `gsd-planner`: no plan task in this phase may create, modify, or restyle a `.vue` file, view,
  component, token, or stylesheet. The only permitted file edits are `.github/workflows/ci.yml`,
  `backend/tests/unit.test.js` (temporary, reverted in 01-02), and `AGENTS.md` (01-03).
- `gsd-executor`: there is nothing to implement visually. Reference this contract only to confirm
  you did **not** touch the UI.
- `gsd-ui-checker`: dimensions are evaluated against *non-regression of the unchanged surfaces*,
  not against new screens. Sections marked "not applicable" are honest scope statements, not gaps.
- The design tokens/typography/color below are **inherited facts read from the existing
  `frontend/src/styles/tokens.css` + `base.css` on 2026-09-23** — recorded so later UI phases have
  the contract in one place, and so this phase can prove it changed nothing.

## Spacing Scale

**Not exercised this phase (no new surfaces).** Declared for contract completeness and future-phase
inheritance; matches values already used in `base.css`. All values are multiples of 4:

| Token | Value | Usage (as already used in base.css) |
|-------|-------|--------------------------------------|
| xs | 4px | Icon gaps, inline padding (`.badge` padding, `gap: 0.25rem`) |
| sm | 8px | Compact element spacing (`.grid` gap, `.field` gaps) |
| md | 16px | Default element spacing (`.card` region gaps, `gap: 1rem`) |
| lg | 24px | Section padding (`.card` padding `1.5rem`) |
| xl | 32px | Layout gaps (`padding: 2rem` blocks, `.page` rhythm) |
| 2xl | 48px | Major section breaks (`.page` padding `3rem`) |
| 3xl | 64px | Page-level spacing (`.section` padding, footer spacing) |

Exceptions (all existing, all multiples of 4, all unchanged): **44px minimum touch target** on
`.btn` and `.input` (`min-height: 44px` [CITED: base.css:71,91]); legacy 12px / 20px / 28px
rem-values already present in `base.css` (0.75 / 1.25 / 1.75rem). **No new spacing introduced this
phase.**

## Color

**Unchanged — 60/30/10 split read from `tokens.css` on 2026-09-23.** The existing app is a dark
theme with one light surface (topbar):

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `#0f0f0f` (`--offline`) | Page background, mobile menu, dark surfaces |
| Secondary (30%) | `#171717` (`--raised`) | Cards, inputs, table rows; topbar inverse surface `#f9f9f9` (`--online`) |
| Accent (10%) | `#fbba00` (`--spark`) | Reserved list below only |
| Destructive | `#ff6b6b` (`--danger`) | `.btn.danger`, `.alert.error` border — destructive actions only |

Accent (`--spark`) reserved for — exhaustive list, never "all interactive elements": text links
(`a`), active nav item (`.router-link-active`), primary button fill (`.btn`), card border
(`.card`), badge outline/fill (`.badge`, `.badge.ok`), KPI values (`.kpi`), eyebrow marker
(`.eyebrow`), input focus ring (`:focus` glow), section headings inside cards. Semantic pair:
`--success #ffd466` / `--danger #ff6b6b` (with `-bg` tints) for status only.

**No color changes ship in this phase.**
