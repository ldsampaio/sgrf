<objective>
Close VERIFICATION gap 6 and the underlying advisory on scripted failures: route every scripted failure family through the production decision and reconciliation seam and prove the natural-identity re-read ordering for each of them.

Purpose: The programmable fake can produce a timeout, a lost response, a 409, a 422, a 429, and a 5xx, but nothing in production consumes them. The only test that touches a failure calls a read method by hand, so no production path has ever had to decide what a failed read means or what to do next. The seam that answers those questions must exist and be deterministic before Phase 11 adds writes.
Output: A reconciliation seam that normalizes every failure family, re-reads by natural identity before deciding, and never proposes a write; the CLI wired to it; and a per-family suite with ordering assertions.

Planner assumptions (deterministic edge probe, resolved here):
- OPS-02 concurrency: repeated reconciliation of concurrent and failure evidence is deterministic and never proposes a write. Cross-process arbitration remains Phase 11 REC-05 and is NOT claimed here. Resolved by task 3.
- SAFE-02 unclassified edge: a transport or status failure normalizes to a distinct family and is never accepted as eligibility. Resolved by task 1, asserted in task 3.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| failed remote read to decision | A failed or indeterminate read crosses here and must never be read as an absent object or as success |
| caller-supplied evidence to seam | The normalized evidence, the frozen ci block, and the two computed decisions cross into the seam as parameters; a set the repository does not hold must not be able to reach a decision |
| re-read identity to remote | The re-read crosses the client boundary with an identity taken from the failed attempt; a wrong identity would silently reconcile against a different object |
| test injection to operator surface | A scripted failure plan crosses from a test caller into the decision path and must be unreachable from the command line |
